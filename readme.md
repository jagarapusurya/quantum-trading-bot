# 🚀 Quantum Trading Bot using QNN

This project implements a Quantum Neural Network (QNN) using PennyLane to predict stock price movements and generate trading signals.

## 📌 Features
- Quantum Machine Learning model
- Real-time stock data using TradingView
- BUY/SELL signal prediction
- Uses amplitude embedding for feature encoding

## 🧠 Tech Stack
- Python
- PennyLane (Quantum Computing)
- NumPy
- TradingView TA API

## ▶️ How to Run

```bash
pip install -r requirements.txt
python main.py
